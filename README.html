Key Features

Designed with user convenience and admin productivity in mind, QuickShow provides a full range of industry-standard capabilities.

Seat Layout Selection

Interactive, responsive grid view for selecting preferred seats in real-time with visual indicators for occupied and selected states.

Stripe Checkout

Seamless checkout flows using Stripe API for verified online payments, supporting webhook tracking and booking confirmations.

Automatic Release

Powered by Inngest workflows. Automatically releases held seats and deletes unpaid bookings if payment isn't finished in 5 minutes.

Admin Panel

Comprehensive dashboard listing sales statistics, active shows, booking counts, show additions, and total revenue trackers.

Clerk Authentication

Secure login/registration via Clerk, with automatic user profiles synchronization to MongoDB via secure event listeners.

Email Notifications

Automatic receipt of high-quality confirmation emails powered by Resend API and custom HTML email templates after payments.

Installation & Setup

Follow these instructions to run the application locally on your computer.

Prerequisites

Ensure you have Node.js (v18+) and npm installed. You also need a MongoDB Atlas cluster and accounts for Clerk, Stripe, Inngest, and Resend.

1. Clone the repository

Bash 
git clone https://github.com/Swayamkushwaha/QUICKSHOW.git
cd QUICKSHOW

2. Set up Backend environment variables

Create a file named .env in the server folder with these keys:

server/.env 
MONGODB_URI="your_mongodb_atlas_uri"
CLERK_PUBLISHABLE_KEY="your_clerk_publishable_key"
CLERK_SECRET_KEY="your_clerk_secret_key"
CLERK_WEBHOOK_SECRET="your_clerk_webhook_secret"
STRIPE_SECRET_KEY="your_stripe_secret_key"
STRIPE_WEBHOOK_SECRET="your_stripe_webhook_secret"
RESEND_API_KEY="your_resend_api_key"
INNGEST_EVENT_KEY="your_inngest_event_key"
ADMIN_EMAIL="swayamkushwaha605@gmail.com"

3. Run the Backend server

Terminal 
cd server
npm install
npm run server

4. Set up Frontend environment variables

Create a file named .env in the client folder:

client/.env 
VITE_CLERK_PUBLISHABLE_KEY="your_clerk_publishable_key"
VITE_BASE_URL="http://localhost:3000"
VITE_CURRENCY="$"

5. Run the Frontend client

Terminal 
cd client
npm install
npm run dev

Admin Access Guide

QuickShow includes strict authorization checks to secure dashboard statistics and show creation routes from unauthorized users.

Authorized Admin Emails

We've updated the backend authorization middleware to grant access to swayamkushwaha605@gmail.com and any email configured in the ADMIN_EMAIL environment variable.

To access the Admin Panel, follow these simple steps:

  1. Log in with your Clerk account associated with the email swayamkushwaha605@gmail.com.
  2. As soon as you log in, the backend verifies your email and returns isAdmin: true to the frontend application.
  3. A green **"Admin Panel"** button will instantly render next to your user profile picture in the main Navbar.
  4. Clicking the button will direct you to the nested admin subroutes (/admin, /admin/add-shows, /admin/list-shows, and /admin/list-bookings) to control shows and view booking statistics.
